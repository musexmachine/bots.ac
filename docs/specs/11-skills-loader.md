## Context

The portable-behavior layer. Loads `skill.yaml`, `SKILL.md`, prompts, input/output schemas, and hooks; exposes skills to any built-in agent through a uniform contract. Skills are agent-agnostic; hooks receive only the documented skill I/O, never agent-internal state. `skill.yaml` (manifest) and `SKILL.md` are required; other files are convention. Derived from SPEC.md → Skills.
