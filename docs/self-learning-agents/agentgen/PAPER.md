# AgentGen: Enhancing Planning Abilities for Large Language Model based Agents via Environment and Task Generation

## Summary
AgentGen aims to improve the planning abilities of LLM agents by automatically synthesising **diverse environments and tasks** for instruction tuning.  The method uses LLMs to generate a wide range of environments and tasks and then applies a **bidirectional evolution algorithm (BI‑EVOL)** to adjust task difficulty gradually, providing a smoother learning curve【201043912280171†L10-L66】.  By exposing Llama‑based agents to hundreds of generated environments during training, AgentGen improves planning performance and, in some cases, allows models to outperform GPT‑3.5 and GPT‑4 on planning benchmarks【201043912280171†L60-L66】.  The work demonstrates that environment and task generation can enhance agent skills without requiring real‑world data.
