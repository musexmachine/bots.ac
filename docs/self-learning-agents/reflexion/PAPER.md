# Reflexion: Language Agents with Verbal Reinforcement Learning

## Summary
Reflexion presents a framework where language agents learn from **verbal feedback** instead of parameter updates.  After completing a task, the agent reflects on its own performance in natural language and stores this reflection in episodic memory【816944510090118†L20-L49】.  The agent then conditions on past reflections to guide future decisions, effectively implementing verbal reinforcement learning.  Experiments demonstrate significant improvements in decision‑making, coding and reasoning tasks compared with baseline agents.  By using linguistic feedback rather than gradient updates, Reflexion offers a lightweight way for agents to self‑improve and may complement memory‑based systems.
